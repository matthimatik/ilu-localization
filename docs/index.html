stages run independently (parallel group highlighted) and only exchange JSON artifacts via the ArtifactStore · visualization is a post-run tool, not a stage

associate

Links each pose box to OCR quads whose centres fall inside its visible corner bbox (configurable margin_px) — no global tracking, just geometric association per frame.

fuse

Validates ISO 6346 owner codes and check digits, picks category (container / trailer), size class and the identification method: code > embedding_rank > unknown.

schema-first

Pydantic models (ImageRef, PoseBoxes, TextSpots, Associations, ILURecords) versioned with schema_version — the contract between all stages.

Architecture

A library + CLI tools, not a service. Everything is a stage registered in one dictionary.

JSON-artifact DAG

Stages only talk through runs/<run_id>/<stage>/<name>.json. Config inputs reference "stage/artifact"; a missing artifact fails the stage and aborts the run. The manifest is rewritten after every stage.

Content-addressed cache

Stage outputs are keyed on class + config JSON + input file hashes in .cache/stages. Re-running an unchanged pipeline replays from cache; --no-cache forces execution.

External backends

Sibling repos, not vendored: ../ilu-pose-estimation (YOLOv8 corners + PnP), ../ilu-detection (TRUDI instance segmentation), ../mmocr (DBNet++ det + RobustScanner rec, fine-tuned on TRUDI id text).

Golden-file testing

Unit + fixture e2e always run in CI-less pytest; backend integration tests are opt-in via RUN_BACKEND_TESTS=1. Fusion output is diffed against tests/golden/ilu_records.json.

Post-run visualization

tools/visualize_run.py renders a completed run: cv2 2D overlay (wireframes, OCR quads, id badges, detail strip), a plotly 3D world scene with camera frustum, and a self-contained HTML report.

Config-driven

Pipelines are YAML (configs/pipeline*.yaml) mapping string impl keys to registered stage classes. Relative paths resolve against the config's base dir.

Quickstart

Python ≥ 3.11, managed with uv. The fixture pipeline needs no GPU.

# install (dev group: pytest)
uv sync

# all tests, incl. fixture end-to-end
uv run pytest

# fixture pipeline (no GPU)
uv run python tools/run_pipeline.py

# real backends (GPU + sibling repos)
uv run python tools/run_pipeline.py \
    --config configs/pipeline_backends.yaml

# render overlay + 3D scene + report
uv run python tools/visualize_run.py
